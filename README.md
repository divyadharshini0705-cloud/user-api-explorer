
# User API Explorer – QA Edition

A web-based REST API exploration and testing tool
built using HTML, CSS and JavaScript.

## Features
- Fetch user data using REST API
- Search users by name and email
- View individual user information
- Display formatted JSON responses
- Handle HTTP and network errors
- Automated API validation test runner
- HTTP status code validation
- JSON structure and required field validation
- Duplicate user ID detection
- Response time measurement
- PASS / FAIL test execution reports

## Technologies
- HTML5
- CSS3
- JavaScript
- REST API
- JSON
- Fetch API
- Async/Await

## API Used
https://jsonplaceholder.typicode.com/users

## Testing Scenarios
1. API request validation
2. HTTP status code validation
3. JSON response validation
4. Array data validation
5. Required fields validation
6. Duplicate ID validation
7. Response data validation

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Launch index.html using Live Server.
4. Click Run All Tests to execute API checks.

## Purpose
This project demonstrates REST API integration,
response validation, basic automated API checks
and error handling.
