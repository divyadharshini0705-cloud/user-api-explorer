
# User API Explorer

A simple REST API exploration tool built using HTML, CSS and JavaScript.

## Features
- Fetch user data using a REST API
- Display user information
- Search users by name and email
- View JSON responses
- Handle API errors

## Technologies Used
- HTML
- CSS
- JavaScript
- REST API
- JSON

## API Used
https://jsonplaceholder.typicode.com/users

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## Purpose
This project demonstrates basic REST API integration, API response handling and data display using JavaScript.
